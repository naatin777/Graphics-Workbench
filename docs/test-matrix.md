# Test Matrix

このファイルは何がテストされていて何が未テストかを把握するための地図です。
capabilityごとにEvidenceの強さとgapを記録します。

現時点では、正解画像・正解PDFを使った内容比較は導入していない。既存のfixture、生成fixture、metadata・geometry oracleで確認できる範囲を記録し、内容比較が必要な箇所は`Known gap`へ残す。正解fixtureの仕様、作成、比較許容値は別taskで扱う。
