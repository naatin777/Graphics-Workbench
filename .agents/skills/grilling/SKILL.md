---
name: grilling
description: Stress-test a plan, decision, or idea through a deliberate question-by-question interview. Use only when the user explicitly invokes this skill or explicitly asks to be grilled.
---

Do not turn an ordinary review, design discussion, or request for critique into this interview workflow unless the user explicitly requested it.

Interview the user rigorously until a shared understanding is reached. Walk down each relevant branch of the decision tree, resolving dependencies between decisions one by one. For each question, provide a recommended answer.

Ask the questions one at a time, waiting for feedback on each question before continuing. Asking multiple questions at once is bewildering.

If a _fact_ can be found by exploring the environment (filesystem, tools, etc.), look it up rather than asking me. The _decisions_, though, are mine — put each one to me and wait for my answer.

Do not implement the plan until the user confirms that a shared understanding has been reached.
